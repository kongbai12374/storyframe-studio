## 发布及作品验收

- **线上部署**。公网首页、设置页、前端入口文件和 CSRF 接口返回正常。Web 与 Worker 运行 `adbb539`，健康检查通过。数据库迁移已应用至 `0006`，两块西乡塘画布与对应成片文件均可查到。
- **照片版**。Worker 调用 FFmpeg，以 8 张实景照片、旁白和字幕合成 60 秒，确认 H.264/AAC、1280×720、24 帧/秒。
- **H3 动态版**。真实调用 IndexTTS2 生成四段旁白，向 H3 提交四个短片任务。四段原片生成完成，在 Windows 上剪成 60 秒并导回镜序。成片为 1280×720、24 帧/秒，已抽查字幕与音量、验证受鉴权的下载及文件一致性。[画布与实测流程](canvas-flow-guide.md)
- **备份恢复**。当天的真实备份已在隔离目录完成恢复，SQLite 完整性及业务表均通过。用模拟数据验证活动任务查询失败时不会停服，配置文件缺失时上一份备份可保留。
