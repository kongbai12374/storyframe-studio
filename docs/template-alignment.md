# 轻量模板对照

已实现：Django/DRF与React/TS，SQLite WAL，本地素材，两应用容器；Session/CSRF与邀请账号；Fernet配置中心、LLM/TTS协议适配与调用额度/审计；剧本、分镜、Markdown；图片与配音上传；持久单消费者队列、幂等、进度/取消/重启恢复；字幕/缩放/硬切/H.264合成；Django Admin；画布自动保存、revision、白名单DAG及串行执行；测试、源码包和备份恢复。

实现调整：不再使用有已知漏洞提示的React Router6，升级至兼容React18的Router7；前端行为保持BrowserRouter/Routes模式。Django模型按轻量边界集中在core app，避免为凑原始模板7个App拆空文件。每画布每次仅允许一个合成节点，避免多个成片的存储与恢复语义膨胀。

待真实联调：用户自行配置LLM/TTS Key后验证API兼容性、额度和实际模型输出；无真实密钥时AI流程会明确失败，不返回模拟成功。
明确暂缓：AI视频生成、通用多智能体、并行/循环工作流、WebSocket、自动AI内容审查、向量检索、PDF、复杂转场/H.265/4K、实时多人协作、PostgreSQL/MinIO/Redis/Celery。
首版未提供背景音乐叠加配置、原图保留、私有模型管理员网络白名单和超过100项素材/剧本的画布下拉检索；当前SSRF策略统一拒绝私网。长时间运行中断后的半成品由人工核查，未建设付费供应商侧幂等/查询适配。一般任务最长15分钟，网络阶段取消需等待有限网络超时后生效。
任务异常与取消即时清理临时目录，worker重启清理遗留临时目录；worker空闲循环定期清理超过24小时且不属活动任务的临时目录。上传音频文件直接使用，网络TTS结果未知不重发。
这些边界在用户手册和最终报告保留，不把暂缓能力列作已验收。
