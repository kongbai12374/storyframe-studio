# 故障排查

无法访问本机8010：确认SSH转发仍运行且本机端口未被占用；服务器Nginx只监听127.0.0.1:8010，这是预期。检查sudo nginx -t和curl http://127.0.0.1:8010/health/。
任务不执行：查看docker compose ps与logs --tail100 worker；确认主机探针systemctl status drama-host-metrics及指标更新时间。内存/磁盘不足时准入会拒绝；不要删除指标检查绕过保护。
health degraded：worker心跳超过20秒或尚未启动，检查容器日志、数据库锁、资源探针和OOMKilled。Django web单独存活不代表可执行任务。
重启后interrupted：表示上次任务被中断，先核查供应商结果再手动重试。不要直接把数据库状态改为queued。
图片被拒：检查真实文件类型、10MB/1600万像素限制；SVG/GIF/伪造扩展名不受支持。配音超过分镜时长需要编辑时长，平台不会静默截断。
画布409：重新载入或另存副本。非法连线保存失败时先撤销错误连线。素材被引用时删除返回409，需要先解除引用。
AI连接失败：先查已配置的服务类型、HTTPS地址、模型权限和配额，确认供应商支持相应协议。公网地址解析失败/私网地址会被拒绝。unknown调用记录表示无法确定是否已收费，不能盲目重复执行。
数据库繁忙：10秒busy timeout后返回503，短暂退避再试。确认只有一个worker，不要运行多个迁移或长事务。
日志目录：docker日志有5MB×2轮转，任务媒体处理日志最大1MB，任务失败展示类型。不要在排障中打印API Key或.env。
