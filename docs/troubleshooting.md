# 故障排查

适用应用版本 `adbb539`。先确认是本地开发还是生产部署，并记下访问地址、任务编号、当前阶段和错误字段。

| 现象 | 核对方法 |
|---|---|
| 开发页面登录返回 403 | 统一打开 `http://127.0.0.1:5173`，核对 `CSRF_TRUSTED_ORIGINS` 和 Vite 的 8011 代理目标。 |
| 回环 8010 无法访问 | 核对 SSH 转发、本机端口占用及服务器 `nginx/studio.conf`。在服务器请求 `http://127.0.0.1:8011/health/`。 |
| 公网 `/health/` 返回 403 | 生产站点将健康接口限制在回环。用主机上的 `curl http://127.0.0.1:8011/health/` 和 `docker compose ps` 检查。 |
| 页面仍显示旧版 | 对照公网首页中的 `/assets/index-*.js` 与服务器 `frontend/dist/index.html`。核对 Web 与 Worker 的镜像修订，切换完成后刷新页面。 |
| 任务一直排队或健康状态为 `degraded` | 确认 Worker 心跳和容器状态，查看 `docker compose logs --tail 100 worker`。检查主机指标文件更新时间、磁盘余量和容器是否被 OOM 终止。 |
| 备份没有出现新的日期目录 | 查看 `systemctl status drama-backup.timer` 与备份日志。任务活跃会跳过，活动任务查询失败或文件校验失败会中止，完成后才会出现正式目录。 |
| 媒体被拒或合成失败 | 检查真实文件内容、图片大小、音频时长及每个分镜的图片关联。图文合成检查 FFmpeg、ffprobe 和中文字体。 |
| 保存画布返回 409 | 重新载入最新版本，或另存副本保留编辑。删不掉被引用的素材或任务时，先解除对应引用。 |
| 数据库繁忙 | SQLite 等待超过限制时可短暂退避再试。核对只有一个 Worker，迁移和长事务没有并行占用数据库。 |

## 供应商任务失败

1. **立即报 401、403、405** 时，先核对令牌分组、域名、提交路径、查询路径和鉴权头。HTTP 405 历史定位方法见 [AutoDL 排障记录](autodl-405-fix.md)。
2. **尺寸或时长被拒绝**时，核对供应商接受的值。独立视频页的 30 秒上限是平台输入范围；实际模型可以更短。若工作流要求 `768p横` 等枚举，检查模板是否应使用固定值。[视频参数](video-api-guide.md)
3. **参考素材读不到**时，核对 `PUBLIC_ORIGIN`、签名路径、过期时间和模板占位符。需要把语音交给视频供应商时，从独立视频页选择参考音频；画布中的配音合成是在视频生成后混入旁白。[画布流程](canvas-flow-guide.md)
4. **任务中断或响应未知**时，有原供应商任务 ID 则继续查询；没有 ID 时先查供应商侧记录，避免重复提交。任务详情的「重新生成」可能再次计费。

分享错误时提供任务编号、HTTP 状态、供排查的阶段和时间。用脱敏值替代 API Key、Cookie、短期签名链接和 `.env` 内容。[部署检查](deployment-guide.md)
