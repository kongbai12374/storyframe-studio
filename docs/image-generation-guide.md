# 文生图、多图视频与删除功能

更新日期：2026-11-07。访问地址和两道登录方式不变。

## 配置图片 API

1. 打开“个人与 API 配置”，添加服务，类型选择“图片生成 API”。
2. 填入自己的名称、模型、API Base URL 与 API Key。密钥只填专用输入框。
3. 根据供应商文档调整接口映射。默认示例为同步 POST /images/generations、JSON 请求、Base64 图片返回。也可点击“载入图片 URL 示例”。示例只描述协议，不代表任意模型都支持该参数。
4. Base URL 和提交路径会拼接，例如 https://api.example.com/v1 加 /images/generations。不要把完整生成路径重复填进 Base URL。
5. “检查配置”只检查地址和密钥可读取，不执行付费生成。

图片默认映射的 request_body 为 model、prompt、size、n，分别使用 {{model}}、{{prompt}}、{{size}}、{{count}}。图片结果路径沿用现有通用适配器的 video_url_field 字段，默认 data；可以指向字符串或最多4个结果的数组。数组项可为字符串或含 url / b64_json 的对象。output_format 为 base64 或 url。若供应商只返回单张，可设置 data.0.url / data.0.b64_json，生成张数选1。

其他 JSON 接口可自定义同步/异步提交路径、任务ID字段、查询路径、状态字段及结果路径。异步接口用 mode=async，并按供应商文档设置 poll_path、task_id_field、status_field、success_values 等。文件上传、流式SSE、专有签名和仅支持平台上传文件ID的接口需要单独适配，当前不能直接套用 JSON 示例。

OpenAI 风格请求及返回字段参考：https://developers.openai.com/api/reference/resources/images/methods/generate 。模型由用户自行填写；默认不强制添加 response_format，以免不支持此参数的模型拒绝请求。

## 使用与限制

- 左侧“文生图”选择图片服务、提示词、尺寸和张数。每次1–4张，供应商需支持相应尺寸和数量。
- 图片任务在同一串行队列执行。成功后结果页预览，图片自动进入自己的素材库，带“AI生成”标签。
- 仅接受真实 PNG/JPEG/WebP，单张最多10MB、1600万像素。进入现有轻量素材流水线，会转成适合视频制作的 JPEG 与缩略图；不保留透明通道或原始大图。
- 存储配额只按素材计算一次。任务 JSON 不保存Base64、密钥或私有文件路径。
- 同步响应总计最多24MB、等待约120秒；较慢供应商应使用异步接口。HTTPS公网直链会立即下载保存，不跟随重定向；不同域名的CDN不携带API密钥。
- 已提交但没有取得任务ID的请求不会自动重复发送。异步恢复只查询原任务；手动“重新生成”会读取当前服务配置，可能再次计费。

## 多图视频

“视频生成”可勾选最多9张参考图片，按勾选顺序发送，可“前移”调整。供应商模板：

```json
{"prompt":"{{prompt}}","images":"{{images_data_urls}}"}
```

images_data_urls 和 images_base64 会变为真正的数组，不是拼接的文本。占位符必须独占整个字符串。旧 image_data_url / image_base64 仍可使用，读取第一张图。

画布 API 视频节点可连接最多9个图片节点，按连线创建顺序收集。图片来源可以是上传素材，也可以是文生图结果。当前文生图通过独立页面执行，完成后在画布图片节点中选择素材。

多选不会自动让纯文生视频模型支持多图。供应商必须有相应模型和映射；只接受外网URL、上传文件ID或multipart的多图接口需要对应上传适配，不能直接使用上述Base64数组。原 AutoDL H3 文生视频配置保持不变，没有自动切换成多图模型。

## 删除与整理

- 任务中心、素材库、剧本列表和画布列表都支持勾选、全选本页、批量删除。每页最多20项，删除前确认；单项失败会显示原因，其余选中项可继续处理。
- 任务中心和任务详情可删除已结束任务；活动任务必须先取消并等待停止。删除任务会移除记录、日志及对应本地视频文件，释放视频存储；生成的图片、剧本独立保留。
- 素材删除会释放实际文件与缩略图，被剧本、画布或活动任务引用时拒绝删除。对多图任务使用精确图片ID检查。
- 画布结果节点引用的任务不能删除；画布引用的剧本不能删除。先解除关联即可。
- 删除画布保留素材和已有任务快照；已提交任务使用冻结输入继续执行。
- 删除是永久操作，没有回收站。功能上线不会自动清理任何现有用户内容。
