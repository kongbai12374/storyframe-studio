# 新手快速上手：从梗概到配音短片

本教程带你完整跑一遍：配置 AI 服务、生成剧本和文字分镜、在画布上生成分镜图片与配音、连接视频流程并查看结果。AI 服务使用你自己的供应商账号，实际能力和费用以供应商为准。

## 1. 准备服务

登录镜序后打开“账号与服务配置”，按需添加并启用服务：

- **LLM 剧本生成**：填写供应商提供的模型名称、HTTPS Base URL 和 API Key。平台按 OpenAI 风格的 `chat/completions` 协议调用。
- **TTS 配音**：配置支持的语音服务。若供应商使用工作流接口，在服务类型选“TTS 配音”后勾选“使用 JSON 工作流配音”，并按供应商文档核对接口映射。
- **图片生成 API**：想在画布里自动生成分镜图时配置。提交/查询路径、返回字段等映射必须符合供应商接口。
- **视频生成 API**：想生成动态视频时配置，并按供应商文档填写接口映射。

检查服务已启用、模型 ID 和接口映射正确。配置检查不会真正调用模型；生成任务才会访问供应商并可能收费。不是所有供应商都兼容当前接口格式。

## 2. 生成剧本和文字分镜

1. 打开“剧本与分镜”，在“从一个梗概，展开故事”输入故事梗概，并选择风格。
2. 示例梗概：

   > 暴雨夜，经营旧书店的林夏发现一本书里夹着十年前好友留下的车票。她循着车票地址找到已经改名的旧车站，却遇见正在等同一班末班车的故人。两人必须在列车进站前说出当年分开的真相。

3. 点击“AI 生成剧本”。页面会跳转到任务详情；等待任务完成后，在剧本列表打开生成结果。
4. 检查标题、每个分镜的“画面描述”“台词 / 字幕”和时长。AI 生成的场景列表就是文字分镜；补充或修改后点击“保存修改”。每个分镜为1–60秒，整部剧本最多12个分镜、总时长不超过60秒。

## 3. 新建画布并放入节点

打开“创作画布”并点击“新建画布”。画布左侧是节点栏，点击节点添加后，在右侧属性面板选择关联内容、服务或填写文字。先按下面顺序添加：

- **剧本**：在“关联内容”里选择刚生成的剧本。
- **分镜**：也选择同一个剧本；用它把剧本内容提供给后续图片、配音和视频节点。
- **AI 分镜生图**：每个需要图片的分镜添加一个。设置对应的“分镜序号”（第一个镜头填1、第二个填2），选择图片 API 服务；可在备注里补充角色外观、画面风格等统一要求。
- **AI 配音**：选择已启用的配音 API 服务。配音文本留空时读取连接过来的剧本台词；也可以在文本框里输入单独的旁白。参考音频是可选项，仅用于服务支持时模仿音色，不会直接成为成片旁白。
- **API 视频生成**：选择视频 API 服务，设置视频时长和横/竖屏方向。可补充镜头运动、节奏等提示词。
- **配音合成**：把生成的视频和音频合成到一起，设置成片时长。
- **结果预览**：用于显示最终结果。

若只想先验证“剧本 → 配音”，暂时不加图片和视频节点也可以：添加“分镜”和“AI 配音”，连好后选中配音节点，点击“执行此节点及依赖”。

## 4. 连线

在画布模式下，从节点右侧圆点拖到下游节点左侧圆点。按下面连接：

1. **剧本 → 分镜**
2. **分镜 → 每个 AI 分镜生图**
3. **分镜 → AI 配音**
4. **分镜 → API 视频生成**
5. **每个 AI 分镜生图 → API 视频生成**
6. **API 视频生成 → 配音合成**
7. **AI 配音 → 配音合成**
8. **配音合成 → 结果预览**

连线表示数据依赖：执行下游节点时，系统会先执行它依赖的上游节点。不要把节点连成回路；如果连错，选中节点后可在右侧点击对应“断开输入 / 输出连线”。手机或不方便拖拽时，可切换“列表模式”选择和编辑节点，但连线操作建议使用画布模式。

## 5. 执行并查看成片

1. 确认右上方状态显示“已保存”。画布会自动保存，也可以点击“保存”。
2. 核对配音服务、图片与视频服务均已选好；图片节点的分镜序号在剧本范围内；视频和配音时长设置合理。
3. 执行前核对模型和时长。调用可能产生费用，实际扣款以供应商账单为准。
4. 点击“执行流程”直接提交。系统按依赖顺序执行节点，进度和结果会显示在画布与任务中心。
5. 完成后在画布结果区预览或下载视频。失败时先读任务错误和节点状态，修正服务配置或输入，再继续未完成流程；不要对状态未知的付费请求盲目重复提交。

## 连线速查

- 文字分镜：AI 生成的剧本包含场景描述、台词和时长。
- 分镜图片：由“AI 分镜生图”节点按分镜序号单独生成；也可先在图片生成页生成或上传，再用“图片素材”节点接入。
- 配音：由“AI 配音”节点生成音频；“配音合成”节点需要同时连接 API 视频和 AI 配音。
- 视频：由“API 视频生成”节点调用所选供应商。当前流程每次只支持一个视频生成 / 合成节点，最多连接9张参考图片。
- 多图注意：把图片节点接到视频节点后，视频服务的 JSON 请求映射也必须配置多图字段（如 `images_data_urls` 或 `image_url_0`）。若供应商映射不支持多图，先按其接口配置映射或只使用已支持的输入。
- 执行范围：点击“执行流程”时，若画布有“结果预览”节点，会执行结果节点及其全部上游依赖；不相关的空节点不会执行。
