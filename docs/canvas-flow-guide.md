# 画布流程指南

适用应用版本 `adbb539`。本文覆盖本地合成、带配音的 API 视频，以及多段成片的制作方法。[项目入口](../README.md) · [从梗概到配音短片](quick-start-guide.md)

## 三种制作方式

| 目标 | 建议流程 |
|---|---|
| 用照片、配音和字幕做短片 | 为剧本每个分镜选择图片和可选配音，保存剧本后连接 **剧本 → 本地合成 → 结果预览**。合成上限为 60 秒。 |
| 生成动态画面，再合入旁白 | **分镜 → AI 分镜生图 → API 视频生成 → 配音合成 → 结果预览**。也可把素材库里的图片直接接到 API 视频生成。给配音合成同时连接 AI 配音节点或已有音频节点。 |
| 给视频供应商传参考音频 | 在独立的**视频生成**页或 `video_api` API 请求里选择最多 3 段参考音频和 9 张参考图。确认当前工作流的模板映射接受这些素材。[视频 API](video-api-guide.md) |

**配音合成**把生成好的视频和一条旁白合成 MP4。独立视频页的**参考音频**会随请求交给供应商，是否及如何使用取决于模型。对于同一画布，当前一次执行最多包含一个「本地合成」或「API 视频生成」节点。带「AI 分镜生图」或「配音合成」的全流程请使用 API 视频路径。需要独立做照片版时，另建一块只包含本地合成链的画布。

## 素材与配音

- **分镜图**。设置 AI 分镜生图的序号，每个节点读取一个分镜并生成一张图。上游图片也可来自素材库。视频节点按连线顺序收集有引用的参考图，供应商模板应当配置多图占位符。
- **音色参考**。在 AI 配音或配音合成面板上传或选择 MP3、WAV，可试听。上限为 20 MB、60 秒。配音合成面板上传参考音频时可以复用已有 AI 配音节点，或新建并连好 AI 配音节点。确认绑定了工作流服务、配音文本和参考素材。
- **成片旁白**。把已有旁白作为音频素材接入配音合成，或把 AI 配音的输出接入配音合成。音色参考由服务用来生成新音频，播放的是新生成的旁白。
- **签名素材**。供应商需要读取图片或音频时，可由 `PUBLIC_ORIGIN` 签出约一小时内有效的链接。仓库配置要求公网 HTTPS 入口能访问签名路径。素材库和成片下载仍按用户归属鉴权。[公网配置](public-https-guide.md)

## 保存、执行和续跑

1. 保存画布再执行。自动保存有延迟，看到「已保存」后，点「执行流程」或「执行此节点及依赖」。有结果节点时，默认以结果节点和上游依赖作为执行范围。
2. 系统为任务固定画布版本、节点顺序、素材引用和映射。相同用户重复提交同一个幂等键会返回原任务，使用新键可以启动新任务。生成直接入队，供应商费用以账单为准。
3. 重新打开画布可查看最近任务。带检查点的全流程可复用已成功的节点输出；有远端任务 ID 时继续查询。若原提交状态未知且没有 ID，先核查供应商记录。另起一轮生成可能再次计费。
4. 删除任务前先解除结果节点对任务的引用。任务删除时会清理没有其他任务引用的中间及最终视频。生成的图片、音频和剧本按各自的素材或项目记录管理。[使用手册](user-manual.md)

历史任务中仍可看到旧版记录的费用预留。当前执行请求按幂等键去重，旧预算字段不会作为新任务的收费上限。

## 已验收作品

**2026-11-21 西乡塘。** 照片版使用 8 张实景照片、旁白和字幕，由镜序 Worker 调用 FFmpeg 合成 60 秒视频。动态版实测 AutoDL IndexTTS2 和 H3，每段向 H3 传入两张实景参考图及该段旁白，生成四段约 15 秒的视频。最终在 Windows 上剪辑、加字幕、混音并导回镜序。H3 画面为实景参考基础上的 AI 演绎。

**2026-11-07 人物分镜。** 当时用 DeepSeek Flash 写剧本、IndexTTS2 生成配音。AutoDL 图片任务被拒绝后，改用 ImageGen 生成两张分镜图并导入；双图 H3 生成后将旁白合入，最终得到 10 秒、1344×768、24 帧/秒的 H.264/AAC 视频。旧版流程记录的 2.70 元为保守预留。随后修复了音频素材到配音合成的连接，验证参考音频上传、试听和执行快照。[音频连线验收](canvas-audio-link-fix-20261107.json) · [参考音频上传验收](reference-audio-upload-20261107.json)

完整回归和发布核对见[测试与验收](test-report.md)。
