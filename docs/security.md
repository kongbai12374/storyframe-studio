# 安全检查记录

已实现并测试：Session/CSRF、邀请制、密码哈希和验证、所有业务资源归属、私有媒体、SQL ORM参数绑定、JSON对象/大小/图类型验证、Fernet密钥加密与脱敏、SSRF公网解析检查及TLS固定连接IP、禁重定向、参数数组启动媒体进程、子进程组取消、配额/幂等/资源准入、任务输入快照与lease写回。
自定义AI请求连接解析时验证过的IP并使用原域名TLS SNI/证书校验，避免二次DNS解析绕过。仅443 HTTPS。供应商错误响应不原样回传，也不在日志记录Key。
上传流式写入，实际图片解码与音频签名检查，图片像素超限返回验证错误。媒体路径由服务端随机生成并限制在数据根目录；私有文件不是公开可枚举静态目录。
运行容器非root、只读镜像、无Docker socket或特权、有限CPU/内存和日志，前端静态CSP禁止外部脚本。

前端npm audit最后结果0项已知漏洞；Python pip check通过。未运行完整Python依赖漏洞扫描、独立渗透测试或正式安全认证，不宣称不存在全部漏洞。
