# 安全设计

适用应用版本 `adbb539`。部署前核对自己的域名、证书、用户权限和备份存放位置。[公网 HTTPS 配置](public-https-guide.md) · [部署指南](deployment-guide.md)

## 登录和数据归属

浏览器用 Django Session、CSRF 和密码校验登录。普通用户只能读写自己的剧本、素材、画布和任务；管理后台由 Django 的账号与权限控制。公网后台是否可达由所选 Nginx 站点决定，开通后匿名访问仍要经过后台登录。

上传按实际文件内容、尺寸和类型校验。私有文件保存在运行目录，媒体加载和成片下载走鉴权接口。用于供应商的素材链接约一小时内有效。持有有效链接的供应商可以读取指定素材，链接需要与 API Key 一样避免写入公开日志或文档。[素材链接实现](../backend/core/asset_links.py)

## 对外服务与媒体进程

- API 密钥加密保存，列表展示脱敏尾号。任务保存供应商配置快照，调用时按用户归属查找密钥。编辑服务时可保留原密钥。
- 自定义供应商地址须为公网 HTTPS、443 端口。DNS 结果按公网地址检查，连接使用校验过的 IP，并使用原域名做 TLS 验证。下载时只给同源请求加鉴权头。
- 媒体命令采用参数数组启动，Worker 管理取消和进程组。容器以非 root 用户运行，根文件系统只读，内存、CPU 和日志均有限额。
- 任务幂等按用户和请求键生效。已取得远程任务 ID 时可继续查询。提交结果未知时先核对供应商记录，显式重新生成可能再次计费。[重试规则](video-api-guide.md#费用恢复和取消)

## 备份和验收

包含数据库、媒体、`.env` 或站点配置的备份应按生产数据保护。恢复旧数据库时需要原来的加密密钥。每日备份的校验、轮换和隔离恢复步骤见[备份恢复](deployment-guide.md#备份恢复)。

自动化测试覆盖身份与归属、上传边界、外部地址校验和重试行为。历史依赖检查只代表当时锁定的版本。依赖升级、完整渗透测试和离机灾备应按具体部署另行验证。[发布基线与测试覆盖](test-report.md)
