# 使用手册

1. 通过本机入口登录；需要其他创作者账号时，由管理员打开/admin/创建普通用户，不勾选staff/superuser即可。不要共享管理员密码。
2. 在素材库拖入图片或配音。图片≤10MB/1600万像素；音频≤20MB/60秒，类型需真实有效。文件只对所属用户可见。文件名搜索、类型筛选和标签帮助整理。
3. 新建剧本，填标题、梗概与分镜。每镜头1–60秒，总共≤60秒，最多12镜头。选择图片和可选配音；台词会成为字幕。上下移动调整顺序。先保存再执行；版本冲突时重新载入，避免覆盖别人的修改。
4. 视频合成选择剧本，确认每镜头有图片。无配音时不勾选TTS即可无声合成；勾选后没有音频的镜头会调用你已配置的TTS并计入供应商费用。音频超过分镜时长会拒绝合成，需先调整。
5. 任务中心看阶段和日志。排队任务可取消；运行任务会终止媒体进程后取消。失败或中断需人工查看再重试，系统不会自动重发结果未知的付费请求。
6. 完成后在任务详情预览和下载MP4。当前为720p、24fps、中文ASS字幕与硬切，配音或提示音是素材内容；测试样例中的声音只是提示音。

## API配置

在“个人与API配置”选择LLM或TTS，填写供应商支持的模型ID、HTTPS Base URL、API Key。当前仅实现OpenAI风格chat/completions和audio/speech协议，并不表示所有自定义供应商都兼容。配置按用户隔离，只有后4位可见。首次保存需要完整密钥，编辑留空保留原密钥；支持停用和删除。
“检查配置”仅验证URL解析与密钥可读，不请求收费模型，也不保证模型权限。真正执行AI任务才会调用服务。模型、价格、余量由供应商决定；平台剩余调用次数是本平台准入额度，不等于供应商余额。
尚未配置任何真实密钥，真实AI调用等待用户配置联调。已新增用户自选视频生成API；视频生成页默认走用户API，本地图片/字幕合成保留在单独选项卡。配置方法见video-api-guide.md。

## 画布

新增画布，从左侧放入剧本、分镜、图片、音频、合成、结果或便签节点。点击节点在右侧选择关联内容和编辑文字。拖动端点连线，右侧也可断开连线。画布名称与内容防抖自动保存，显示已保存才可安全离开；另存副本可保留版本冲突中的本地修改。
推荐流程：剧本→合成→结果，图片/音频可接入合成补齐未指定素材；也可先在剧本编辑器给每个分镜关联不同素材。
AI剧本节点使用备注作为梗概，TTS节点使用配音文本或输入剧本台词。只有点击“执行流程”或“执行此节点及依赖”才会调用；移动、连线和自动保存不会调用AI。
一个流程每次最多一个合成节点，100节点/200连线；执行串行，输入快照固定。执行中修改画布不会修改已有任务。结果可在任务中心查看，即使原节点随后删除。
手机可切换列表模式选择节点并编辑属性，不必完成精细拖拽。撤销重做仅当前会话有效，刷新后从最后保存状态继续。
